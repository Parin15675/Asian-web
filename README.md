
# Mongolia Single-Page Website (12 Sections)

This is a clean, single-page site for a school project. It includes 12 sections that match the rubric, bilingual (EN/TH) content, and YouTube placeholders.

## How to use
1. Open `index.html` and search for `VIDEO_ID`. Replace each with your real YouTube ID (the part after `v=`).  
   Example: `https://www.youtube.com/watch?v=dQw4w9WgXcQ` → `VIDEO_ID = dQw4w9WgXcQ`
2. Replace images in `/images` with your own royalty-free images. Keep filenames or update the `src` in HTML.
3. Edit colors/fonts in `assets/style.css` if you want.
4. Test on desktop & mobile.

## Deploy (choose one)
### Netlify (fastest)
- Go to app.netlify.com → New site → Drag & drop the entire folder.
- Or zip the folder and drag, Netlify will unpack it automatically.

### Vercel
- Push this folder to a GitHub repo.
- Import the repo at vercel.com → Deploy.

### GitHub Pages
- Create a new GitHub repo, upload files.
- Settings → Pages → Deploy from `main`, root folder.

## Navigation
Top menu anchors jump to each section. “Top” button appears after scrolling.

Good luck & have fun! 🎉
